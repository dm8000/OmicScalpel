# Datasets renamed to first author et al. + year of publication.
#
# Only the ones with a publication that could be confirmed. Each was checked
# against NCBI rather than read off the old nickname, and two of the nicknames
# turned out not to name the first author at all:
#
#   Rozen.BMI          -> the paper is Emont et al. 2022 (Nature). "Rozen" is
#                         not its first author. PMID 35296864, and GEO
#                         GSE174475 (43 samples, which matches this dataset).
#   Bluher.Lynes...    -> Lynes et al. 2017 (Nature Medicine). "Bluher" is not
#                         the first author either.
#   Moustafa...2022    -> El-Sayed Moustafa et al. 2022 (Int J Obes). The PMID
#                         recorded in the sheet, 32817962, is the 2020 medRxiv
#                         preprint; the published version is PMID 35589964.
#   Civelek...2017     -> Civelek et al. 2017 (Am J Hum Genet), PMID 28257690,
#                         GEO GSE70353 (770 samples, matching).
#   Mirabegron.Leiria  -> Leiria et al. 2019 (Cell Metab), PMID 31353262.
#
# GTEX_adipose keeps its name: it is a consortium with no first author, and
# nobody calls it anything else.
#
# Three more were traced from the GEO sample ids in their own SampleID column,
# which is provenance the sheet never recorded as such:
#
#   mice.HFD.chow      -> GSM3082780 belongs to GSE112740, PMID 29642370,
#                         Cao et al. 2018 (Int J Mol Sci)
#   mice.old.young...  -> GSM4007560 belongs to GSE135391, PMID 32795388,
#                         Panic et al. 2020 (eLife)
#   obese.vs.lean...   -> GSM1223777 belongs to GSE50574, PMID 25518011,
#                         Ferrante et al. 2015 (Pediatr Res)
#
# In all three the lab's own Author column already named that first author,
# which is a check the three agree on rather than one source repeated.
#
# The other nine have neither a publication, a GEO accession, nor GEO sample
# ids. They are left alone.
#
# Format:  <current name> | <new name>
